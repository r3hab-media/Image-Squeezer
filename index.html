    What it does

    1. Nothing leaves your device

      Every image is compressed by WebAssembly inside this tab. There is no server and no upload.

    2. Up to 25 images at once

      Drop, browse or paste a batch. Download each one, or all of them in a single zip.

    3. Strips location data

      Re-encoded images lose their hidden metadata, including the GPS position your phone saved.

    4. Hits a file size

      Set a target in KB and it finds the highest quality that fits. Or cap the width or long edge.

    5. Opens iPhone photos

      HEIC, AVIF, BMP and GIF come out as JPEG or PNG that every site accepts.

    6. Works offline

      Install it from the browser menu and it keeps working with no connection.
